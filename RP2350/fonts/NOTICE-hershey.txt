Hershey Roman Simplex (rowmans.jhf, and the table generated from it,
../hershey_simplex.c), used for the CE-150 plotter emulation's lettering.

The file rowmans.jhf is from https://github.com/kamalmostafa/hershey-fonts
(hershey-fonts/rowmans.jhf), which distributes it under the Hershey fonts
licence below -- the font data only, not that project's GPL code (none of
which is used here). hershey_simplex.c is a conversion into a C table, not
the U.S. NTIS format.
